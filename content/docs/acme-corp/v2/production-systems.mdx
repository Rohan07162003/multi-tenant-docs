# Production Systems

Acme Corp operates multiple production lines across our facilities, each optimized for specific product categories.

## Production Line Overview

### Assembly Line A1 - Consumer Products
- **Capacity**: 10,000 units/day
- **Products**: Small appliances, tools
- **Shift Schedule**: 3 shifts, 24/7 operation
- **Quality Gates**: 5 inspection points

### Assembly Line A2 - Industrial Equipment  
- **Capacity**: 500 units/day
- **Products**: Heavy machinery, industrial tools
- **Shift Schedule**: 2 shifts, 16 hours/day
- **Quality Gates**: 8 inspection points

### Assembly Line A3 - Custom Orders
- **Capacity**: Variable
- **Products**: Bespoke manufacturing solutions
- **Shift Schedule**: 1 shift, 8 hours/day
- **Quality Gates**: Custom validation per order

## Production Planning System

Our ERP system coordinates:
- Raw material scheduling
- Workforce allocation
- Equipment maintenance windows
- Delivery commitments

### Key Metrics
- **OEE (Overall Equipment Effectiveness)**: Target 85%
- **Defect Rate**: < 0.5%
- **On-Time Delivery**: >98%

## Integration Points

The production system integrates with:
- Inventory management
- Quality control systems
- Shipping and logistics
- Customer order management
