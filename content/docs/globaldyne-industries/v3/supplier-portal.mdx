## API Example: Supplier Onboarding

The Supplier Portal provides an API for onboarding new suppliers programmatically.

**Base URL:**
```text
https://api.globaldyne.com/v3
```

### Authentication
All API requests require an API key in the header:
```text
Authorization: Bearer YOUR_API_KEY
```

### Endpoint: Create Supplier

```http
POST /suppliers/onboard
```

**Request Body:**
```json
{
  "company_name": "Acme Parts LLC",
  "contact_email": "contact@acmeparts.com",
  "country": "USA",
  "certifications": ["ISO 9001", "TS 16949"]
}
```

**Response:**
```json
{
  "supplier_id": "SUP-12345",
  "status": "pending_review"
}
```
