# Quick Start Guide

This guide will help you get started with our platform in just a few minutes.

## Prerequisites

Before you begin, make sure you have:

- Node.js 18+ installed
- npm or yarn package manager
- A text editor or IDE

## Installation

### Step 1: Install the CLI

```bash
npm install -g our-platform-cli
```

### Step 2: Create a New Project

```bash
npx create-our-app my-project
cd my-project
```

### Step 3: Start Development Server

```bash
npm run dev
```

Your application will be available at `http://localhost:3000`.

## Basic Usage

### Making Your First API Call

```javascript
import { ApiClient } from 'our-platform-sdk';

const client = new ApiClient({
  apiKey: 'your-api-key'
});

const response = await client.get('/api/users');
console.log(response.data);
```

### Configuration

Create a `.env` file in your project root:

```bash
# Create a .env file
API_KEY=your_api_key_here
API_URL=https://api.ourplatform.com
```
