# API Reference v2.0

Welcome to our platform's enhanced API reference documentation. This covers version 2.0 of our REST API with new endpoints and improved functionality.

## Base URL

```
https://api.ourplatform.com/v2
```

## Authentication

### API Key Authentication
Include your API key in the Authorization header:

```http
Authorization: Bearer YOUR_API_KEY
```

### OAuth 2.0 (New in v2.0)
For enhanced security, use OAuth 2.0 for user-specific operations:

```http
Authorization: Bearer YOUR_OAUTH_TOKEN
```

## New in v2.0

- **Batch Operations**: Process multiple items in a single request
- **Webhooks**: Real-time event notifications
- **GraphQL Support**: Alternative query language
- **Enhanced Filtering**: Advanced query parameters
- **Real-time Data**: WebSocket connections for live updates

## Core Endpoints

### Users API

#### List Users (Enhanced)

```http
GET /api/v2/users
```

**Query Parameters:**
- `page` (integer): Page number (default: 1)
- `limit` (integer): Items per page (default: 20, max: 100)
- `sort` (string): Sort field (`created_at`, `name`, `email`)
- `order` (string): Sort order (`asc`, `desc`)
- `filter[status]` (string): Filter by status (`active`, `inactive`)
- `search` (string): Search in name and email

**Example Request:**
```http
GET /api/v2/users?page=1&limit=50&sort=created_at&order=desc&filter[status]=active
```

**Response:**
```json
{
  "data": [
    {
```

### Projects API v2

#### Advanced Project Search

```http
GET /api/v2/projects/search
```

**Query Parameters:**
- `q` (string): Search query
- `tags[]` (array): Filter by tags
- `status` (string): Project status
- `created_after` (date): Filter by creation date

## Webhooks (New in v2.0)

### Register Webhook

```http
POST /api/v2/webhooks
```

**Request Body:**
```json
{
  "url": "https://your-app.com/webhooks/ourplatform",
  "events": ["user.created", "project.updated", "payment.completed"],
  "secret": "your_webhook_secret"
}
```

### Webhook Events

| Event | Description |
|-------|-------------|
| `user.created` | New user registration |
| `user.updated` | User profile changes |
| `project.created` | New project created |
| `project.updated` | Project modifications |
| `payment.completed` | Payment processed |
