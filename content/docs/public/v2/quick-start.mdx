# Quick Start Guide v2.0

This guide will help you get started with our enhanced platform v2.0 in just a few minutes.

## Prerequisites

Before you begin, make sure you have:

- Node.js 18+ or Python 3.8+ installed
- npm, yarn, or pip package manager
- A text editor or IDE
- Git (for cloning examples)

## Installation Options

### Option 1: NPM Package (Recommended)

```bash
npm install -g @ourplatform/cli@latest
```

### Option 2: Python Package

```bash
pip install ourplatform-cli
```

### Option 3: Docker Container

```bash
docker run -it ourplatform/cli:latest
```

## Quick Setup

### Step 1: Initialize Your Project

```bash
# Create a new project with interactive setup
ourplatform init my-project

# Or use a specific template
ourplatform init my-project --template=api-client
```

Available templates:
- `api-client` - REST API client application
- `webhook-handler` - Webhook processing service
- `dashboard` - Analytics dashboard
- `microservice` - Microservice template

### Step 2: Configure Authentication

```bash
cd my-project
ourplatform auth login
```

Or set up manually:

```bash
# Set your API key
export OURPLATFORM_API_KEY="your_api_key_here"

# Or create a .env file
echo "OURPLATFORM_API_KEY=your_api_key_here" > .env
```

### Step 3: Start Development

```bash
# Start with hot reloading
npm run dev

# Or with debugging enabled
DEBUG=ourplatform:* npm run dev
```

Your application will be available at `http://localhost:3000`.

### Interactive Examples

```javascript
import { PlatformClient } from '@ourplatform/sdk';

// Enhanced client with auto-retry and caching
const client = new PlatformClient({
  apiKey: process.env.OURPLATFORM_API_KEY,
  environment: 'production', // or 'staging'
  retryAttempts: 3,
  cacheEnabled: true
});

// Async/await with error handling
try {
  const users = await client.users.list({
    filter: { status: 'active' },
    sort: { created_at: 'desc' },
    limit: 50
  });
  
  console.log(`Found ${users.pagination.total} users`);
} catch (error) {
  console.error('API Error:', error.message);
}
```

### Batch Operations

```javascript
// Create multiple users in one request
const newUsers = await client.users.batchCreate([
  { name: 'Alice', email: 'alice@example.com' },
  { name: 'Bob', email: 'bob@example.com' },
  { name: 'Charlie', email: 'charlie@example.com' }
]);

console.log(`Created ${newUsers.length} users`);
```

### Webhook Integration

```javascript
import { WebhookValidator } from '@ourplatform/sdk';

// Validate and process webhooks
app.post('/webhooks/ourplatform', (req, res) => {
  const validator = new WebhookValidator(process.env.WEBHOOK_SECRET);
  
  if (!validator.verify(req.body, req.headers['x-signature'])) {
    return res.status(401).send('Invalid signature');
  }
  
  const { event, data } = req.body;
  
  switch (event) {
    case 'user.created':
      console.log('New user:', data.user);
      break;
    case 'project.updated':
      console.log('Project updated:', data.project);
      break;
  }
  
  res.status(200).send('OK');
});
```

## Advanced Configuration

### Environment Configuration

```javascript
// config/development.js
module.exports = {
  api: {
    baseUrl: 'https://api-staging.ourplatform.com/v2',
    timeout: 10000,
    retryAttempts: 3
  },
  features: {
    caching: true,
    realTimeUpdates: true,
    analytics: false
  }
};
```

### Custom HTTP Client

```javascript
import { PlatformClient, HttpAdapter } from '@ourplatform/sdk';

// Use your preferred HTTP library
class AxiosAdapter extends HttpAdapter {
  constructor() {
    super();
    this.client = axios.create({
      timeout: 5000,
      // your custom configuration
    });
  }
}

const client = new PlatformClient({
  apiKey: 'your-key',
  httpAdapter: new AxiosAdapter()
});
```
